# Plant.aí 🌱

MVP de um SaaS de fidelidade para estabelecimentos comerciais. Cada ponto acumulado é uma **seed** e o programa conecta fidelidade a impacto ambiental por meio do plantio de árvores.

## Incluído

- Landing page.
- Painel do estabelecimento/tenant.
  - Cadastro de clientes.
  - Seeds, usuários e árvores.
  - Relatório de árvores plantadas.
  - Relatório social por faixa etária e sexo.
- Painel do usuário.
  - Nome.
  - Seeds acumuladas.
  - Árvores plantadas.
  - Progresso para a próxima árvore.
- Painel administrativo Plant.aí.
  - Gestão de tenants.
  - Expiração das contas.
  - Relatórios globais de clientes, usuários e árvores.
- Dados de demonstração persistidos no navegador com localStorage.

## Execução

Abra `index.html` ou publique no GitHub Pages.

## Produção

Este MVP é frontend. Para produção, conectar API e banco, autenticação, isolamento por tenant, RBAC (admin/tenant/usuário), auditoria, LGPD, assinatura/cobrança e integração verificável com projetos de plantio.

**Seed → fidelidade → impacto → árvore.**
